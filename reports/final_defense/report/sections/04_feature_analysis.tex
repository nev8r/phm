\section{特征分析}

\subsection{manual\_basic 特征族}

本文使用 manual\_basic 作为最终主线特征集。该特征集不是简单堆叠统计量，而是围绕轴承振动退化的可解释信号变化构造。特征筛选、推荐矩阵和泄漏检查来自项目特征分析报告 \cite{project_feature_analysis}。表 \ref{tab:feature-families} 总结了主要特征族及其含义。

其中 RMS、mean\_abs、std 和 ptp 通常反映振动幅值和能量变化；kurtosis 与 skewness 对冲击和非对称分布敏感；spectral centroid、bandwidth 和 spectral entropy 则描述频谱重心、频带扩散和频谱复杂度。合成幅值通道 mag 用于同时利用水平和垂直方向信息，但当 \code{mag__time__rms} 参与 HI/FPT 构造时，需要在最终模型中谨慎处理其标签源争议。

\subsection{任务级分析方法}

不同任务需要不同证据：

\begin{itemize}
  \item RUL：关注特征与寿命比例的相关性、单调性和退化趋势。
  \item HealthState：关注不同退化阶段之间的特征分布是否可分。
  \item EarlyFault：关注正常阶段与早期异常阶段之间的效应差异。
\end{itemize}

因此，特征分析报告同时使用 RUL 相关性、退化行为分数、健康阶段箱线图、早期故障效应图和推荐矩阵，而不是只输出一个总分表。
