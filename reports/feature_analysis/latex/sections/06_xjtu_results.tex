\subsection{主划分结果}

XJTU-SY 主划分下，\config{manual_basic} 的核心结论是 amplitude / energy-like time-domain features 主导。RUL top 特征主要来自 magnitude 和 horizontal 幅值族；Health State 主划分中 horizontal amplitude 特征很强；Early Fault 主划分同样偏 horizontal amplitude，但后续稳定性分析表明该任务更敏感。

\subsection{工况内稳定性}

Step H 对三个工况分别做 leave-one-bearing-out 分析。结论为：

\begin{itemize}
  \item RUL：magnitude、horizontal 和 vertical 幅值特征在三工况中都较稳定。
  \item Health State：\feature{h__time__mean_abs} 最稳定，\feature{h__time__rms} 和 \feature{h__time__std} 在 C2/C3 更强。
  \item Early Fault：最工况敏感。C1 偏 spectral entropy，C2 偏 peak-to-peak shock，C3 偏 horizontal amplitude。
\end{itemize}

\subsection{跨工况鲁棒性}

Step I 训练于 \config{35Hz12kN}，验证于 \config{37.5Hz11kN}，测试于 \config{40Hz10kN}。由于 ranking 是 train-only，top features 反映训练工况而非所有工况的重新排序。

结论为：

\begin{itemize}
  \item RUL：幅值类特征多数保留。
  \item Health State：magnitude 特征比 pure horizontal 特征更稳。
  \item Early Fault：horizontal amplitude 需要降级为 condition-sensitive；spectral entropy 主要是 Condition 1 信号。
\end{itemize}
