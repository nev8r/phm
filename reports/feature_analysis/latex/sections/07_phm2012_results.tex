\section{PHM2012 结果}

\subsection{\config{manual_basic} 主结果}

PHM2012 official split 下，\config{manual_basic} 在三个任务上均表现出 amplitude-dominant 模式。

\begin{itemize}
  \item RUL：\feature{h__time__mean_abs}、\feature{mag__time__mean}、\feature{mag__time__mean_abs} 排名前列。
  \item Health State：\feature{h__time__mean_abs}、\feature{h__time__std}、\feature{h__time__rms} 最强。
  \item Early Fault：horizontal 和 magnitude amplitude 特征主导，spectral frequency 特征只作为 secondary。
\end{itemize}

\subsection{\config{manual_tsfresh_basic} 对照}

PHM2012 可以成功运行 full-size \config{manual_tsfresh_basic}。分析中有 44 个 ranked features，其中 20 个为 \feature{tsfresh__} 特征。

进入 top-10 的 \feature{tsfresh__} 特征主要包括：

\begin{itemize}
  \item \feature{tsfresh__h__standard_deviation}
  \item \feature{tsfresh__h__root_mean_square}
  \item \feature{tsfresh__h__variance}
  \item \feature{tsfresh__h__maximum}
  \item \feature{tsfresh__v__standard_deviation}
  \item \feature{tsfresh__v__root_mean_square}
\end{itemize}

这些特征能够进入 RUL、Health State 和 Early Fault 的 top-10，但其物理含义主要重复手工 RMS、standard deviation、variance、maximum 等统计量。因此它们更多是对 amplitude story 的确认，而不是新的主线特征族。
