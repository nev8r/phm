# 端到端运行与输出解读手册

本手册解释项目如何从命令运行到输出文件，并说明每个输出物能证明什么。

![真实训练证据链](assets/training-evidence-chain.png)

## 1. 三类运行方式

| 方式 | 命令或入口 | 目的 |
| --- | --- | --- |
| 合成数据 demo | `uv run python main.py` | 快速验证主流程、训练器、评价和图表输出 |
| notebook 示例 | `examples/*.ipynb` | 给使用者展示 loader、训练和论文复现入口 |
| 真实数据复现 | `run_paper_cnn_lstm_attention_reproduction`、`run_paper_xlstm_transformer_reproduction` | 在 `data/external` 上完成论文结构复现和指标输出 |

这三类方式互相补充。demo 不能替代真实数据复现；真实训练也不适合每次 CI 都全量运行，所以 notebook smoke 使用 1 epoch 保证入口可执行。

## 2. 常用命令

快速跑通：

```bash
uv run python main.py
```

执行全量测试：

```bash
uv run --extra dev pytest -q
```

执行 notebook smoke：

```bash
BEARING_EXAMPLE_EPOCHS=1 uv run --extra dev pytest tests/test_examples_notebooks.py -q
```

真实数据论文复现示例：

```bash
BEARING_EXAMPLE_OUTPUT_ROOT=tmp/paper_repro_real_metrics \
BEARING_EXAMPLE_EPOCHS=8 \
uv run python - <<'PY'
from USTC.SSE.BearingPrediction.examples import run_paper_cnn_lstm_attention_reproduction

result = run_paper_cnn_lstm_attention_reproduction(
    max_samples_per_entity=48,
    prefer_real_data=True,
)
print(result["comparison_path"])
PY
```

## 3. 输出目录结构

实验输出通常位于 `outputs/` 或通过环境变量指定到 `tmp/`。真实训练输出不提交仓库，但文档记录命令和指标摘要。

| 文件 | 来源 | 解读方式 |
| --- | --- | --- |
| `config.json` / `config.yaml` | `ExperimentTracker` | 记录模型、学习率、epoch、batch size 和运行配置 |
| `history.csv` | 训练循环 | 每行对应一个 epoch，用于证明训练真实执行 |
| `metrics.json` | 测试阶段 | 单模型单数据集的指标摘要 |
| `predictions.csv` | `BaseTester` | 每个样本的 target、prediction 和可能的 metadata |
| `comparison_metrics.csv` | 论文复现 workflow | 多模型、多数据集对比表 |
| `attention_weights.csv` | attention 模型 | 检查模型对时间步的权重分配 |

## 4. 如何判断训练不是静态示例

判断训练是否真实执行，不能只看 PPT 上的指标。至少要能追溯以下证据：

1. 运行命令中包含真实数据目录和 epoch 设置。
2. workflow 返回 `comparison_path`。
3. 每个模型目录下存在 `history.csv`。
4. `history.csv` 至少包含 8 行 epoch 记录。
5. `predictions.csv` 中 target 和 prediction 行数与 `prediction_count` 一致。
6. `comparison_metrics.csv` 中包含模型名、数据集名、RMSE、R2、Score 等列。

## 5. 常见异常与处理

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| workflow 回退到 demo 数据 | `data/external` 缺失或目录结构不匹配 | 检查 XJTU-SY、PHM2012 解压路径 |
| PHM2012 温度列为空 | 温度文件缺失或未与加速度文件匹配 | 检查 Training_set/Test_set 原始目录 |
| R2 为负 | 小样本、短 epoch、尺度偏差或模型拟合不足 | 不包装结果，说明复现边界 |
| Score 数值很大 | PHM 类指数惩罚对方向和尺度敏感 | 与 Huang Score 分开展示 |
| notebook 运行慢 | 真实数据训练较重 | smoke 使用 1 epoch，真实训练放到 `tmp/` |

## 6. 文档引用规则

正式文档只记录可复查摘要，不提交大型运行输出。建议引用方式：

- 命令：写完整环境变量和 Python 调用。
- 路径：写 `tmp/.../comparison_metrics.csv` 作为本地复查路径。
- 指标：写数据集、模型、epoch、样本数、RMSE/R2/Score。
- 边界：注明小样本、8 epoch、非作者源码级复刻。
