# 指标驱动实验结果说明与 Open-Source SOTA 对照

本文档更新 `next goal.md` 的落地状态。当前结论不是“已经完整追上全部 SOTA”，而是：

> 项目已经建立 open-source SOTA target 表、gap 计算和证据摘要；新增 `tsfresh` 自动特征分析、`tsfresh` RUL baseline、`sktime` panel baseline 和 strict same-config repeated seed 摘要；RULSurv RSF 已完成 Python 3.11 port，读取 XJTU-SY `35Hz12kN` 工况 5 个轴承的 616 个原始 csv 快照，入模 611 个正 RUL 快照样本，在 RULSurv-compatible 25% censored row-level 5-fold CV 上 3 seeds mean true MAE 为 6.926416 min，低于 12.6 min target，状态为 `PROTOCOL_PASS`；在本项目 Bearing1_3 held-out migration 上 mean true MAE 为 14.307856 min，低于 15.75 min gate，状态为 `MIGRATION_PASS`；AutoRUL、GNN、Weibull KIML 等外部路线已有 source pin 与依赖 probe 失败日志，但尚未产出本地指标。

## 3. 当前 Gap

| 本地方法 | target | local best | local mean | local std | run_count | best gap | mean gap | 状态 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| Feature-Transformer | 0.0885 | 0.055434 | 0.096967 | 0.035179 | 5 | 0.00% | 9.57% | PASS |
| XLSTM-Transformer | 0.0583 | 0.064558 | 0.101090 | 0.037141 | 5 | 10.73% | 73.40% | NEEDS_OPTIMIZATION |
| manual 19 features + RandomForest | held-out Bearing1_3 | 0.343059 | 0.345365 | 0.002136 | 3 | - | - | RUN_RECORDED |
| tsfresh selected features + RandomForest | held-out Bearing1_3 | 0.315266 | 0.315629 | 0.000265 | 3 | - | - | RUN_RECORDED |
| sktime RocketRegressor | held-out Bearing1_3 | 0.255794 | 0.263706 | 0.005757 | 3 | - | - | RUN_RECORDED |
| sktime TimeSeriesForestRegressor | held-out Bearing1_3 | 0.314206 | 0.315919 | 0.001224 | 3 | - | - | RUN_RECORDED |
| strict 50 epoch XLSTM-Transformer rerun | held-out Bearing1_3 | 0.145374 | 0.157007 | 0.019885 | 3 | - | - | RUN_RECORDED |
| strict 50 epoch Feature-Transformer rerun | held-out Bearing1_3 | 0.177856 | 0.186688 | 0.010375 | 3 | - | - | RUN_RECORDED |
| RULSurv RSF port / original 25% censored row-level CV | 12.6 min | 6.521192 | 6.926416 | 0.293073 | 3 | 0.00% | 0.00% | PROTOCOL_PASS |
| RULSurv RSF port / project Bearing1_3 holdout | 12.6 min | 14.044586 | 14.307856 | 0.187967 | 3 | 11.46% | 13.55% | MIGRATION_PASS |

解释：

- `local best` 用于观察是否存在接近论文目标的能力；
- `local mean` 用于防止 cherry-pick，是当前是否稳定接近 SOTA 的主要判断；
- `tsfresh` 特征选择只使用 train bearings，held-out Bearing1_3 只用于最终评估；
- `sktime` baseline 使用 3D panel numpy 输入，RocketRegressor 当前优于手工 19 维和 tsfresh selected RandomForest；
- strict rerun 使用同一 50 epoch 配置 JSON 和 3 个 seed，是重复协议证据；由于 held-out split 与论文 reference 协议不同，仍不等价于论文全量复现达标；
- Feature-Transformer 的 repeated mean gap 小于 10%，达到“接近强基线”的门槛；
- XLSTM-Transformer 的 best run gap 为 10.73%，但 repeated mean gap 高，不能宣称稳定追上 SOTA。
- RULSurv RSF port 在原论文 row-level 协议近似复现上低于 target，可以作为至少一个开源强模型复现完成证据；
- RULSurv-compatible 5-fold 是 row-level CV，同一 bearing 的不同时间点可能进入不同 fold，因此只能解释为原协议复现，不等价于 held-out-bearing 泛化；
- RULSurv RSF port 在本项目 Bearing1_3 holdout split 上使用固定 conservative survival quantile 解码后 mean gap 为 13.55%，进入 target 的 25% gap 内；原 repo split 和本项目迁移 split 仍必须分开报告。

## 5. 后续优化任务

1. 建立 AutoRUL 独立环境或容器，按 `auto-sktime` tag `v0.1.0` 重跑 `femto_bearing`，生成 `open_source_sota_reproduction_summary.csv` 的真实外部复现行。
2. 继续扩展 RULSurv RSF port 到更多 XJTU 工况，验证 conservative survival quantile 解码是否在其他 held-out bearing 上稳定。
3. 固定 XLSTM-Transformer 的最佳配置，至少 3 个 seed、50 epoch 重复训练；验收以 mean gap 而不是 best gap 为准。
4. 若 XLSTM repeated mean gap 仍高于 25%，继续调 `sequence_length`、时间索引、loss、batch size、hidden size、样本数和特征归一化策略。
5. 不得把 `ATTEMPTED_EXTERNAL_ENV_BLOCKED`、`REFERENCE_ONLY`、未重跑外部 target 或单次 best run 写成“已追上 SOTA”。
